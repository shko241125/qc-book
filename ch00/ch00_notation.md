# 책 앞에: 기호와 비용 단위

2026-11-11 · Gosh

양자컴퓨팅 입문·심화서 · 책 앞에 · 본문 어디서든 기호나 숫자의 단위가 헷갈리면 이 쪽으로 돌아온다. 같은 글자가 장마다 다른 뜻으로 쓰인 곳은 숨기지 않고 표에 적었다.

## 1. 읽는 규약

- **큐비트 순서는 빅 엔디안이다.** |q₀q₁…⟩에서 q₀가 왼쪽·상위 비트이고 텐서곱도 q₀ ⊗ q₁ 순서다(Nielsen & Chuang, Cirq와 같다). Qiskit과 Quirk는 리틀 엔디안이어서, Qiskit 코드의 비트열은 뒤집어 읽는다(3장).
- **회전 게이트**는 Rz(θ) = exp(−iθZ/2) 꼴이다(Rx, Ry도 같다). 위상 게이트는 P(λ) = diag(1, e^{iλ})이고 Z = P(π), S = P(π/2), T = P(π/4)다. P(λ)와 Rz(λ)는 전역 위상만 다르다(2장).
- **전역 위상**만 다른 두 게이트는 같은 게이트로 본다. 제어를 붙이면 그 위상이 상대 위상이 되어 차이가 생기므로, 그럴 때는 본문이 따로 밝힌다(2장 3절·7절. 제어 회전의 분해는 4장 연습문제 3).
- **단위.** ħ = 1로 두고 에너지와 시간을 결합 상수 J의 단위로 적는다. 장치와 벽시계 시간을 다루는 곳에서만 초 단위(ns, µs, ms, s)를 쓴다. 7·14장의 게이트 시간과 T1·T2, 9·16·17장의 논리 게이트 시간과 손익분기, 19장의 FFT와 회로 실행 시간이 그렇다. 엔트로피는 밑이 2인 로그, 곧 비트로 적는다. 분자 에너지는 mHa이고 화학적 정확도는 1.6 mHa다.
- **코드 표시.** "numpy 구현(실행 완료)"는 그 장의 `chNN_*.py`를 실제로 돌린 출력이라는 뜻이다. SDK 코드의 첫 줄에 붙은 "작성됨, 미실행"은 그 코드를 아직 돌려 보지 못했다는 뜻이다(쓴 환경에 SDK가 없었거나, 본문의 발췌라 그대로는 돌지 않거나, 고친 뒤 다시 돌리지 않았다). PennyLane은 `import pennylane as qp`로 쓴다.
- **출처 등급.** A는 교과서·논문·공식 문서로, 정의와 수치의 근거로 쓴다. B는 도구·해설 글과, 원문을 직접 확인하지 못해 2차 서술로 확인한 출처다. 직관을 돕거나 보조 수치를 대는 데 쓰고, 그 경우 본문이 확인 경로를 밝힌다.

## 2. 기호 표

한 글자가 장마다 다른 뜻으로 쓰인 경우는 넷째 열에 적었다. 본문은 그 장에서 쓰는 뜻을 다시 정의한다.

| 기호 | 기본 뜻 | 주로 쓰는 장 | 헷갈리기 쉬운 곳 |
| --- | --- | --- | --- |
| n | 큐비트 수 | 전체 | 19·22장의 커널에서는 특성 수이기도 하다 |
| N | 2ⁿ. 탐색 공간이나 행렬의 크기 | 9·19·20장 | 11장에서는 인수분해할 수. 19장에서는 잔기 수(5절 (5))와 전자 수(5절 (3))로도 쓴다 |
| t | 계수(위상) 레지스터의 큐비트 수. 정밀도는 2⁻ᵗ | 10·11장 | 7장과 12장 이후에서 t는 시간이다. 계수 큐비트 수는 12장에서 t\_b, 16장에서 m, 17장에서 b로 적는다. 15장의 "T가 t개"에서 t는 T 게이트의 수다 |
| φ | QPE가 읽는 위상. 고유값이 e^{2πiφ}이고 φ는 0 이상 1 미만 | 10\~12장 | 1·2장에서는 Bloch 구의 경도와 U(θ, φ, λ)의 각, 7장에서는 펄스의 위상, 16장에서는 QSP 위상각 φ₀…φ\_d다. 5장에서는 순간이동으로 보낼 상태의 이름이기도 하다 |
| M | 표시된 해의 수 | 9장 | 12·16장에서는 진폭 추정의 격자 크기 M = 2^(계수 큐비트 수)이고 Q 호출 수는 M − 1이다. 14장에서는 판독 혼동 행렬, 19장 5절 (3)에서는 공간 궤도 수 |
| γ | 시험 상태와 바닥상태의 겹침 확률. 반복 수는 1/γ, 진폭 증폭을 쓰면 1/√γ | 10·12·17장 | 13·14장에서는 QAOA·HVA의 비용 층 각도(γ, β), 18장에서는 2큐비트 합성의 판정 행렬 γ(U), 7장에서는 진폭 감쇠 채널의 감쇠 확률, 2장에서는 전역 위상의 각 |
| α | 블록 인코딩의 정규화. LCU면 계수 절댓값의 합이고, 호출 수가 이 값에 비례한다 | 16·17·20장 | 12장은 같은 크기의 양을 에너지 이동 w로 적는다. 1\~5장의 α, β는 상태의 진폭이고, 9·12장의 α는 해가 아닌 상태들의 중첩에 붙인 이름이다 |
| L | LCU의 항 수 | 16·17장 | 13장에서는 하드웨어 효율 틀의 층 수 |
| ε | 목표 정밀도(허용 오차) | 전체 | 16장에서는 블록 인코딩 오차와 표식 비율로도 쓴다. 14장의 ε₀₁, ε₁₀은 판독 오류 |
| κ | 조건수(가장 큰 특이값 / 가장 작은 특이값) | 16·17·19·20장 | 16장 부호 함수 근사에서는 문턱의 가파름 |
| r | Trotter 단계 수 | 12장 | 11장에서는 위수(a^r ≡ 1 mod N인 가장 작은 r), 14·19장에서는 게이트당 오류율(무작위 벤치마킹 값), 18장에서는 표본 수다. 19장은 Trotter 단계 수를 글자 없이 "단계"로 적는다 |
| p | QAOA·HVA의 층 수 | 13·18·21장 | 14장에서는 탈분극 채널의 강도(비항등 파울리 오류의 총확률)다. k큐비트 게이트면 d = 2ᵏ이고 r에서 p = r(d+1)/d로 환산한다(2큐비트 1.25배, 1큐비트 1.5배). 17장에서는 가속의 차수(p = 2가 제곱 가속), 11장에서는 N = pq의 소인수다 |
| S | 반쪽 사슬의 얽힘 엔트로피(비트) | 3·15·17\~19장 | 1절의 위상 게이트 S = P(π/2)와 글자가 같다. 9·12·16장의 S₀, S\_f는 반사이고, 16장 Szegedy 워크의 S는 SWAP이다. 19·20장의 I + γS에서 S는 무작위 희소 대칭 행렬이다 |
| χ | MPS의 결합 차원(자름마다 남기는 Schmidt 계수의 수) | 15·17·19장 | 17·19장의 "필요한 χ"는 버린 가중치가 10⁻⁶ 이하가 되는 최소 값이다. 2^S는 그 하한일 뿐이고 실제 값은 몇 배 크다(15장의 "χ ≳ 2^S"는 이 하한을 가리킨다). 15장의 안정자 계수 χ와 16장 진폭 추정의 표식 χ는 다른 양이다 |
| K | 커널 값. 두 특성 상태 Φ(x), Φ(y)의 내적 절댓값의 제곱 | 6·19·22장 | 5·7장의 Kₖ는 Kraus 연산자다 |
| G | 회로의 2큐비트 게이트 수. rG는 오류의 기대 개수 | 19장 | 14장은 같은 수를 N\_CZ로, 곱을 N\_CZ·p\_CZ로 적는다. 그 식의 p\_CZ는 사양서 오류율, 곧 이 표의 r이다 |

## 3. 비용 단위

이 책은 비용을 한 가지로 세지 않는다. 잡음 장치에서는 2큐비트 게이트와 깊이가, 오류 정정 환경에서는 T 게이트가 비싸기 때문이다. 그래서 2부와 4부의 회로에는 가능한 곳마다 세 숫자를 함께 적는다("게이트 비용 기록"). 14장은 장치 연결에 맞춘 뒤의 CZ 수만 적는다.

| 단위 | 무엇을 세는가 | 세는 규칙 |
| --- | --- | --- |
| 2큐비트 게이트 수 | CX(또는 CZ)의 개수 | 기준은 CX와 임의의 1큐비트 게이트, 모든 큐비트가 이어진 장치. 환산: 제어 위상 2(각도가 π인 제어 Z는 CZ 1개), 제어 회전 2, exp(−iθZ⊗Z) 2, SWAP 3, 일반 2큐비트 게이트 3, Toffoli·CCZ 6, Fredkin 8, 이중 제어 위상 8(11장). 14장의 수치는 제어 Z도 2개로 풀고 장치 연결에 맞춰 SWAP을 넣은 뒤의 CZ 수라 더 크다 |
| 깊이 | CX와 1큐비트 게이트로 펼친 회로를 가능한 한 앞당겨 놓았을 때의 층 수 | 1큐비트 게이트도 한 층을 차지한다. 측정은 세지 않는다. 이어 붙은 회전은 합치지 않고 세며, 합친 값을 적을 때는 따로 밝힌다(12장). Toffoli는 4장의 15게이트 순서로 편다 |
| T-count | T 게이트의 개수 | 모든 게이트가 Clifford이거나 π/4의 배수 회전이면 정확한 값(T 1, Toffoli 7). 임의 각도 회전이 있으면 회전 수 R과 T ≈ 3·log₂(1/ε)·R로 적는다(Ross & Selinger 2016). ε = 10⁻⁶이면 회전 하나에 약 60개다. 여기서 ε은 회전 하나의 합성 오차다. 회전이 R개면 오차가 Rε까지 쌓이므로, 회로 전체의 오차를 묶으려면 그 값을 R로 나눠 넣는다 |
| 오라클 호출 수(쿼리 수) | 문제를 담은 게이트 U\_f를 부르는 횟수 | 8·9·11·15·16장. 호출 하나의 게이트 수는 따로 센다. 18장의 "표본·질의 접근"은 고전 자료 구조의 이름이다 |
| 블록 인코딩 호출 수 | 행렬을 담은 유니터리를 부르는 횟수 | 16·17·20장(12장은 7절에서 예고만 한다). α에 비례한다. 호출 하나에는 SELECT와 PREP의 게이트 수가 든다 |
| 샷 | 회로를 한 번 준비해서 재는 일 | 기댓값을 오차 ε로 알려면 샷 수가 1/ε²에 비례한다. 진폭 추정을 쓰면 샷 수가 아니라 상태 준비 회로의 호출 수가 1/ε에 비례하고, 회로가 그만큼 깊어진다 |
| 회로 실행 수 | 변분 알고리즘이 돌린 회로의 총수 | 목적함수 평가 수 × 평가당 샷 수. "평가 수"만 적으면 수백\~수천 배를 숨기게 된다(19장 연습문제 3) |
| TTS₉₉ | 정답을 99% 확률로 한 번 이상 보는 데 드는 총비용 | 한 번의 비용 R(T-count 줄의 회전 수 R과 다른 양이다), 성공 확률 P일 때 R·ln(0.01)/ln(1 − P). 훈련 비용은 한 번 더한다. 비교하는 양쪽의 단위를 맞춘다(19·21장) |
| rG와 무오류 확률 | 게이트당 오류율 r, 2큐비트 게이트 G개인 회로가 오류 없이 끝날 확률 | (1 − r)^G ≈ e^{−rG}. rG가 1을 크게 넘으면 오류 완화의 표본 비용이 지수로 든다(19장). 14장의 오류 예산 N\_CZ·p\_CZ가 같은 양이고, 거기서는 1을 넘으면 결과가 균등 분포에 묻힌다고 적었다 |
| 논리 자원 | 논리 큐비트 수, Toffoli(또는 T) 수, 벽시계 시간 | 오류 정정을 전제한 추정(9·11·17장). 벽시계 시간은 논리 게이트 하나의 시간 가정을 함께 적는다 |
| 고전 비용 | 비교 상대의 연산 수 | 희소 선형계는 비영 원소 수 × 반복 수, MPS는 χ³에 비례, 전수 열거는 경우의 수. 시간 측정값은 이 책을 쓴 컨테이너 기준이다 |

## 4. 판정과 표시

- **판정 셋**(17장): "가능"은 증명된 구조가 있고 고전 경계 검사를 빠져나간 후보, "조건부"는 명시한 조건이 맞을 때만 길이 있는 후보, "탈락"은 체크리스트의 한 단계에서 걸린 후보다. 19장은 작은 크기라서 고전이 빠를 뿐인 경우를 "이 크기에서는 이득 없음"으로 따로 적는다.
- **역할 셋**(19장): 이득 후보, 방법 사례, 반례 사례. 판정은 "양자 이득을 기대할 수 있는가"에, 역할은 "이 책이 왜 싣는가"에 답한다.
- **충실도는 세 가지다.** 상태 충실도는 두 상태 내적의 절댓값 제곱이다(5·10·12·13·15·19장). 평균 게이트 충실도는 게이트 하나를 모든 입력 상태에 대해 평균한 값이다(7·14장). 18장의 회로 합성은 전역 위상을 무시한 공정 충실도 |Tr(U†V)|²/d²를 쓴다(d = 2ⁿ). 둘은 F\_avg = (d·F\_공정 + 1)/(d + 1)로 이어진다. 비충실도는 1에서 충실도를 뺀 값이다. 4장의 게이트 거리 1 − |Tr(A†B)|/d는 제곱하지 않은 값이어서 작은 오차에서는 공정 비충실도의 절반쯤이다.
- **오류율 r과 탈분극 강도 p는 다르다.** 사양서의 게이트 오류는 r이고, 잡음 모형에 넣는 값은 SDK의 규약에 따라 환산한 p다(14장).
- **"예측", "실측", "표본값".** 14장의 하드웨어 수치는 공개 보정 데이터로 만든 잡음 모형의 예측이다. "실측"은 실제 QPU에서 잰 값에만 쓰고, 장치 이름·날짜·작업 ID·샷 수를 함께 적는다(14장 5절의 표, 부록 A). numpy로 난수를 뽑아 얻은 값은 "표본값", 정확히 계산한 값은 "계산값"이라고 부른다.

출처: Ross & Selinger, "Optimal ancilla-free Clifford+T approximation of z-rotations", *Quantum Inf. Comput.* 16, 901 (2016), [arXiv:1403.2975](https://arxiv.org/abs/1403.2975). 나머지 정의는 표에 적은 장의 3절과 10절에 출처가 있다.
